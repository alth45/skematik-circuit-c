undo_undo()

int undo_undo(void);

Kembalikan snapshot terakhir dari stack undo (Ctrl+Z / Edit > Undo). Snapshot state saat ini disimpan ke stack redo, lalu state dipulihkan + sim_recompute. Return 1 bila berhasil, 0 bila stack kosong atau saat RUN. Lihat juga undo_push, undo_redo, undo_can_undo, undo_reset.
