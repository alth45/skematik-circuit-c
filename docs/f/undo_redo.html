undo_redo()

int undo_redo(void);

Terapkan ulang snapshot dari stack redo (Ctrl+Y / Edit > Redo). Snapshot saat ini dikembalikan ke stack undo. Return 1 bila berhasil, 0 bila stack kosong atau saat RUN. Stack redo dikosongkan setiap undo_push baru. Lihat juga undo_undo, undo_can_redo.
